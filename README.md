# A股埋伏追踪终端

> 基于启动形态量化选股 + 个股深度分析的 A 股研究工具

## 项目结构

```
├── index.html                      # 前端单页应用（GitHub Pages 部署）
├── scripts/fetch_daily.py          # 每日选股脚本（GitHub Actions 运行）
├── .github/workflows/daily.yml     # 定时任务配置
└── README.md
```

## 当前功能

### 1. 每日自动选股
- **数据源**：新浪财经（通过 akshare）
- **股票池**：动态获取，支持沪深300/上证50/中证500成分股，可配置
- **选股策略**：启动涨停 → 缩量回踩不破 → 站稳5日线
- **参数可配**：通过前端设置页面调整选股阈值，存储在 Supabase config 表
- **运行方式**：GitHub Actions 每日北京时间 18:00 自动运行

### 2. 前端展示
- **机会雷达**：展示当日候选股票及评分
- **个股分析**：K线图 + 交易计划
- **数据总览**：候选统计
- **选股设置**：可调参数（涨幅阈值、量能倍数、缩量比例等）

### 3. 数据存储（Supabase）
| 表名 | 用途 |
|------|------|
| stocks | 股票基本信息 |
| daily_kline | 日K线数据（最近60天） |
| candidates | 选股结果 |
| config | 选股参数配置 |
| tracking | 持仓追踪 |

## 个股深度分析系统（设计文档）

### 一、分析框架总览

```
输入股票代码
    ↓
① 数据采集：财报(5-10年)、行情、估值历史、资金数据、行业数据
    ↓
② 公司分类：成长 / 成熟 / 周期 / 衰退 / 金融 / 困境反转
    ↓
③ 指标计算：各维度指标 → 标准化(0-100)
    ↓
④ 风险红旗扫描（一票否决 / 扣分）
    ↓
⑤ 估值模块：DCF/RIM/DDM + 相对估值 + 反向DCF → 公允价值区间 + 公允曲线
    ↓
⑥ 综合评分：按公司类型动态加权
    ↓
⑦ 输出：评分卡 + 雷达图 + 公允曲线 + 红旗清单 + 结论标签
```

### 二、分析理论体系

#### 2.1 财务健康与造假检测

| 模型 | 作用 | 核心输入 |
|------|------|----------|
| Piotroski F-Score (0-9) | 9个二元信号判断财务改善：ROA正、CFO正、ROA提升、CFO>净利、杠杆降、流动比率升、未增发、毛利率升、周转率升 | 三大报表 |
| Altman Z-Score | 破产风险预警（<1.8危险，>3安全） | 营运资本、留存收益、EBIT、市值、营收/总资产 |
| Beneish M-Score | 盈余操纵概率检测 | 应收账款指数、毛利指数、资产质量指数、应计比率 |
| Sloan 应计比率 | (净利润−经营现金流)/总资产，越高盈利质量越差 | 利润表、现金流量表 |

**A股特有异常信号**：
- 存贷双高（大量现金同时大量借款）
- 其他应收款/预付款激增
- 研发资本化率飙升
- 审计意见非标、频繁换所
- 关联交易异常

#### 2.2 回报与护城河

- **ROIC vs WACC**：ROIC持续大于WACC才是真正创造价值，比ROE更能剔除杠杆干扰
- **EVA（经济增加值）**：NOPAT − 资本成本，衡量真正的经济利润
- **巴菲特"所有者收益"**：净利润 + 折旧摊销 − 维持性资本开支
- **可持续增长率**：g = ROE × 留存率，检验增速假设是否超出造血能力
- **护城河量化代理**：毛利率长期稳定、ROIC长期高于资本成本、市占率提升、研发/品牌投入强度、客户集中度低

#### 2.3 估值方法

| 方法 | 适用场景 | 说明 |
|------|----------|------|
| DCF（自由现金流折现） | 成长型、成熟型 | 主流估值法，需假设增长率和WACC |
| 反向DCF | 所有类型（推荐） | 已知股价反推隐含增长率，判断市场预期是否合理 |
| DDM（股息折现） | 高分红公司 | 银行、公用事业适用 |
| RIM（剩余收益模型） | 金融股 | 净资产+超额收益折现，银行保险券商适用 |
| EV/EBITDA | 资本密集型 | 剔除资本结构和折旧差异 |
| FCF Yield | 成熟型 | 自由现金流收益率，类似债券收益率思维 |
| PB-ROE | 银行/周期 | 低PB+高ROE=被低估 |
| 历史/行业分位 | 所有类型 | PE/PB在自身5-10年及行业中的百分位 |

#### 2.4 成长性分析

- 营收/利润 3年、5年 CAGR，增速加速或减速
- 盈利预测预期差：分析师一致预期上调/下调、业绩预告超预期
- 先行指标：研发投入占比、合同负债/预收款增速、产能与订单

#### 2.5 资金面与市场行为（A股特别重要）

- 北向资金持股变化
- 机构持仓及变化
- 股东户数变化（筹码集中度）
- 大股东增减持、股权质押比例
- 限售股解禁、回购
- 融资融券余额

#### 2.6 技术面（择时辅助，权重宜低）

- 趋势：MA20/60/250，价格相对年线位置
- 动量：3/6/12个月涨幅、相对强度RS
- 指标：MACD、RSI、布林带、量价关系
- 风险：波动率、最大回撤、Beta

#### 2.7 行业与宏观

- 行业景气度（价格指数、产能利用率、库存周期）
- 竞争格局（CR3/CR5）
- 周期股逆向估值：周期低点PE高、高点PE低，需用PB+重置成本+周期均值利润
- 利率、流动性、政策对估值的影响

### 三、打分模型设计

#### 3.1 六大维度与默认权重

| 维度 | 默认权重 | 主要指标 |
|------|----------|----------|
| 盈利质量 | 25% | 扣非ROE、ROIC、毛利/净利率、CFO/净利润、应计比率 |
| 成长性 | 20% | 营收/扣非利润CAGR、增速加速度、可持续增长率、预期差 |
| 财务安全 | 15% | 资产负债率、有息负债/现金、商誉占比、Z-Score、F-Score |
| 估值 | 20% | 历史分位、行业分位、PEG、FCF Yield、公允价值安全边际 |
| 资金与股东 | 10% | 北向/机构、股东户数、增减持、质押、回购分红 |
| 趋势择时 | 10% | 均线位置、相对强度、量价 |

#### 3.2 按公司类型动态调权

| 类型 | 盈利质量 | 成长 | 财务安全 | 估值 | 资金 | 趋势 | 估值主方法 |
|------|---------|------|---------|------|------|------|-----------|
| 成长型 | 25 | 30 | 10 | 15 | 10 | 10 | DCF + PEG + 反向DCF |
| 成熟型 | 30 | 10 | 15 | 25 | 10 | 10 | DCF + DDM + 股息率 |
| 周期型 | 15 | 10 | 20 | 30 | 10 | 15 | PB分位 + 周期均值盈利 |
| 衰退型 | 20 | 5 | 30 | 30 | 10 | 5 | 清算价值 / PB |
| 银行/金融 | 25 | 10 | 25 | 25 | 10 | 5 | PB-ROE + RIM + DDM |

#### 3.3 单指标打分方法

- **阈值线性映射**：如扣非ROE ≤5%→0分，≥20%→100分，中间线性插值
- **分位数打分**：全市场或行业内百分位排名
- **趋势加分**：指标近3年改善加分，恶化扣分（F-Score思路）
- **缺失值处理**：缺失指标不计入，维度分按剩余指标重新归一，显示数据完整度

#### 3.4 风险红旗机制（不参与加权，直接扣分或封顶）

| 红旗 | 处理 |
|------|------|
| ST/*ST、退市风险、财务造假处罚 | 总分封顶30或标记"不可投" |
| 审计非标意见 | 扣15-20分 |
| 商誉/净资产 > 30%（且行业景气下滑） | 扣分 |
| 股权质押 > 50%、大额解禁临近 | 扣分 |
| 经营现金流连续多年为负但利润为正 | 扣分（盈余操纵嫌疑） |
| Z-Score < 1.8 | 扣分 |

#### 3.5 输出结论标签

- **综合评分**：≥80优秀 / 65-80良好 / 50-65一般 / <50谨慎
- **估值标签**：低估 / 合理 / 高估（取公允价值区间）
- **状态标签**：戴维斯双击 / 双杀 / 价值陷阱嫌疑 / 困境反转

### 四、公允价值曲线

公允价值不是一个点，而是一个区间。通过对关键假设（增长率g、折现率WACC）做敏感性分析，生成三个情景：

- **乐观情景**：行业景气+公司超预期增长
- **基准情景**：分析师一致预期或历史均值外推
- **悲观情景**：行业下行+增速放缓

页面展示为**股价走势 + 三条公允价值带**的叠加图，直观显示当前价格处于低估/合理/高估区间。

### 五、前端页面模块规划

| 模块 | 说明 |
|------|------|
| 总览卡 | 综合评分、公司类型、估值标签、红旗数量、数据置信度 |
| 雷达图 | 六大维度得分可视化 |
| 公允价值曲线 | 股价 vs 公允价值带（悲观/基准/乐观），可切换估值模型 |
| 估值面板 | PE/PB/PEG历史分位、行业对比、反向DCF隐含增长率 |
| 财务趋势 | 10年关键指标折线（ROE、毛利率、现金流、负债率） |
| 风险红旗清单 | 触发项 + 说明 |
| 资金与股东 | 北向、机构、股东户数、质押、解禁日历 |
| 打分明细表 | 可展开，显示每个指标的原始值→阈值→得分→权重 |
| 同业对比 | 与行业前5名并列对比 |
| 参数设置 | WACC、永续增长率、权重自定义 |

### 六、关键设计原则

1. **公允价值输出区间而非单点**：对g和WACC做敏感性分析（热力图）
2. **多模型交叉验证**：DCF、相对估值、历史分位结论一致才给高置信度
3. **行业内比较优先**：同样的ROE/PE在不同行业含义不同，需用行业分位辅助
4. **可解释**：每个得分点都能展开看原始值→阈值→得分→权重
5. **回测校验**：用历史数据验证高分组合是否跑赢基准
6. **合规提示**：页面注明"仅为模型分析，不构成投资建议"

# 波段交易纪律框架

## 核心原则（一句话版）

不要预判主力，要**顺势而为**：看懂趋势和成交量，用事先设定的买卖规则和仓位管理对抗人性。

---

## 快速判断：这只股票能不能做波段？

| 维度 | 合格标准 | ✓ 可做 | ✗ 不做 |
|---|---|---|---|
| **趋势** | 区间震荡 或 缓慢上行 | 高点不断下移 | 持续创新低 |
| **成交量** | 相对均匀，有资金参与 | 忽大忽小、总额低 | 脉冲日放量后冷清 |
| **振幅** | 日均 3%-6% | <3% 覆盖不了成本 | >8% 风险太高 |
| **区间** | 支撑位、压力位清晰 | 无可识别高低点 | 不适合事先设价 |
| **基本面** | 无重大利空、无财报雷、非ST | 重大公告前夕 | 持续亏损、临近解禁 |

**直接排除**：连续涨停、一字板、ST股、临近财报、解禁在即。

## 做T三大纪律

### 1️⃣ 仓位管理（最重要）

```
总资产 100%
├─ 底仓 40-50% ← 原封不动，不做T
└─ 浮动仓 20-30% ← 做波段
    └─ T仓 <= 底仓的 1/3 ← 做高抛低吸
```

- 底仓亏幅承受度 = 愿意亏的金额 ÷ 止损幅度（先算出来再买）
- 波段仓位 20-30%，预期收益 15-20%，折合账户 4-6% 
- 一年 3-4 个波段 ≈ 15-20% 稳健回报（文章估算，非保证）

### 2️⃣ 买卖条件事先写好（二重要）

**不要靠感觉**，必须形成固定、可复用的判断标准：
- 什么价位买？什么价位卖？什么条件止损？
- 写在纸上或手机备忘录里，不临时起意
- 常用工具：布林线、短线均线、K线形态、价格偏离度

### 3️⃣ 心态稳定（三重要）

| 心理陷阱 | 表现 | 对抗方式 |
|---|---|---|
| 怕卖飞 | 赚了不卖，被收割 | 提前写下卖出条件，到了就走 |
| 怕买高 | 一直等更低，踏空 | 接受"确认后买成本略高"，换更高胜率 |
| 追涨杀跌 | 看到涨停追，看到跌停砍 | 追的是**趋势**不是**价格**，要有量 |
| 频繁操作 | 一天操作多次，成本爆表 | 每天最多做一轮T |

## 趋势判断三件套

趋势 = 资金共识，比短期波动更理性。

| 指标 | 上涨信号 | 下跌信号 | 中性 |
|---|---|---|---|
| **股价** | 创新高 | 创新低 | 不温不火 |
| **均线** | 5日 > 20日 > 120日（多头排列） | 反过来（空头排列） | 混乱 |
| **成交量** | 上涨时放量，下跌时缩量 | 下跌时放量（恐慌） | 成交额偏低 |

**原则**：下跌趋势中不急着补仓；上涨趋势中不因小涨就抛。

## 洗盘：区分"可参与"和"不碰"

**两类洗盘**：

| 类型 | 特征 | 应对 |
|---|---|---|
| **底部建仓洗盘** | 倒碗口、打新低、持续磨底，周期不确定 | 不参与，等明确突破信号（底部阳线）再跟 |
| **拉升途中洗盘** | 主力先抛、短期打压，回笼资金，吓走获利盘 | 用日线看周线，等股价重新上涨后再参与 |

**核心逻辑**：不要执着预判洗盘（本来就是为了让人判断不了）。用大周期看小周期，等**盘面确认**才行动，顺势跟随。

## 反T（先卖后买）规则

```
冲高到压力位 
  ↓ 出现"量能跟不上、半小时创不了新高"
  ↓ 卖出T仓
  ↓ 回落 3-4% 或回到支撑位企稳
  ↓ 买回
  
❌ 一票否决：卖出后继续放量上涨、站上新高 → 不追回，接受卖飞
```

---

## 正T（先买后卖）规则

```
回落到支撑位
  ↓ 缩量、不再创新低
  ↓ 买入T仓，同时卖出等量老底仓
  ↓ 反弹 3% 左右
  ↓ 卖出新买的T仓
  
❌ 一票否决：跌破支撑位并放量 → 不再加买
❌ 不做：单边大跌当天（跌幅 >8%）不抄底
```

---

## 补仓和抄底的误区

- "不卖就不算亏" = 认知错误，会让人被困
- 补仓不是解套良药，下跌趋势中越补越亏很常见
- 下跌中散户拿筹码主力不拉，散户止损抛出主力才拉 → 所以常见"买了就跌，卖了就涨"
- **补仓前必问**：趋势是否已经走稳？逻辑是否变化？这笔钱亏了能承受吗？

---

## 成交量看什么

- 上涨趋势中**相对放大** ✓
- 下跌趋势中**被套锁仓**，低迷也正常 ✓
- **杂乱无章、忽大忽小** ✗
- **脉冲日放量后持续冷清** ✗

---

## 买入前自检清单

- [ ] 趋势不是持续向下
- [ ] 成交量有资金参与的迹象（不是脉冲日后被抛弃）
- [ ] 已写明买入价、卖出价、止损价
- [ ] 仓位在计划范围内（底仓 ≤50%，T仓 ≤底仓的1/3）
- [ ] 不是因为"怕踏空"才买
- [ ] 能接受浮亏，且逻辑没变就不慌
- [ ] 没有重大公告、没有解禁倒计时

## 标准分析模板（复盘用）

当分析某个操作时，按以下顺序：

1. **信息确认** → 标的、周期、持仓与成本、当时理由
2. **择时检查** → 趋势 / 成交量 / K线，各给出"偏多、中性、偏空"
3. **纪律检查** → 仓位合规？买卖条件事先设定？情绪化了吗？
4. **主要风险** → 最可能看错的地方是什么？
5. **下一步** → 给出条件式建议（"如果……则……"），不下绝对结论
6. **一句话提醒** → 框架性分析，不构成投资建议

## 常见问题

**Q: 怎么判断是洗盘还是出货？**  
A: 洗盘后股价重新上涨；出货则持续创新低。用大周期判断：日线的洗盘在周线上往往不明显。

**Q: 做T一天赚多少算成功？**  
A: 2-3% 就不错了。乘以 T 仓占比，对账户贡献只有 0.几个百分点。做T的价值是降成本和控制波动，不是翻倍。

**Q: 能补仓摊低成本吗？**  
A: 可以，但前提是趋势已经走稳，逻辑没变。下跌趋势中补仓很容易越补越亏。

**Q: 频繁做T成本会不会很高？**  
A: 会。预期价差必须**大于往返成本的三倍以上**才值得做。往返成本 = 卖出印花税 + 佣金 + 买卖价差，请向券商确认。

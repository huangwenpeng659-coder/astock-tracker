# 个股做T检查清单（通用模板）

**用途**：在决定对某只股票做T前，用此清单逐项核查。打分结果决定是否参与以及风险等级。

> 本清单是纪律框架和决策工具，不构成投资建议。

---

## 一、快速筛选（一票否决）

出现任意一项即**直接排除**，无需打分：

- [ ] 连续涨停或频繁一字板 → 无可操作空间
- [ ] 低流动性（日成交额 < 5000 万） → 价差大、易滑点
- [ ] ST 股或已披露退市风险 → 政策风险
- [ ] 临近财报披露（前 1 周） → 公告冲击
- [ ] 临近解禁或大股东减持期 → 筹码压制
- [ ] 持续创新低、高点不断下移（> 3 周） → 下跌趋势，不碰

---

## 二、八维度打分表

每项：符合 = 2 分，一般 = 1 分，不符合 = 0 分，满分 16 分。

| # | 维度 | 合格标准 | 观察要点 | 得分 |
|---|------|--------|--------|------|
| 1 | 流动性 | 日换手率 3%-10%，成交额稳定 ≥ 1 亿 | 能顺利成交，价差小 | __ |
| 2 | 日内振幅 | 日均 3%-6% | < 3% 覆盖不了成本；> 8% 风险太高 | __ |
| 3 | 趋势 | 区间震荡或缓慢上行 | 避免持续创新低、高点下移 | __ |
| 4 | 区间清晰 | 有可识别的支撑位和压力位 | 才能事先定好高抛低吸价位 | __ |
| 5 | 成交量 | 相对均匀，不是只有脉冲日放量 | 脉冲日后容易回落或突破风险大 | __ |
| 6 | 基本面 | 无重大利空、无财报雷、非 ST | 事件冲击会让 T 失效 | __ |

### 得分判断

| 总分 | 评级 | 建议 |
|---|---|---|
| 13-16 | 比较适合 | 按正常计划做 T |
| 9-12 | 谨慎参与 | T 仓减半，只做少量 |
| 8 分以下 | 不适合 | 不做 T，以持有或观望为主 |

## 三、仓位规划

**原则**：T 是高抛低吸，不改变总持仓。

```
总资产 100%
├─ 底仓 40-50% ← 原封不动，不做 T
│  └─ 本次买入成本/价位：_______
└─ T 仓 ≤ 底仓的 1/3 ← 本次做 T 的上限
   └─ 每天最多一轮
```

**成本检查**
- 预期价差：_______（通常 2-3%）
- 往返成本：_______（卖出印花税 + 佣金 + 买卖价差，向券商确认）
- **规则**：预期价差 > 往返成本 × 3 才值得做

## 五、反 T 规则（先卖后买）

**触发条件**：
- [ ] 冲高到压力位附近
- [ ] 出现"量能跟不上、半小时内创不了新高"的信号
- [ ] 今天没有重大公告或板块利空

**执行**：
1. 卖出 T 仓数量：_____
2. 预期回落价位：_____ （通常卖价下方 3-4%）
3. 接回数量：同卖出数量
4. 接回时间窗口：_____

**一票否决**：卖出后继续放量上涨、站上新高 → **不追回**，接受卖飞，保留底仓。

---

## 六、正 T 规则（先买后卖）

**触发条件**：
- [ ] 回落到支撑位附近
- [ ] 缩量、不再创新低
- [ ] 今天没有重大公告或板块利空

**执行**：
1. 买入 T 仓数量：_____
2. 同时卖出等量的老底仓
3. 预期反弹幅度：3% 左右
4. 卖出价位：_____

**一票否决**：跌破支撑位并放量 → **不再加买**，按原计划处理，不摊平。

---

## 七、每日做 T 前自检清单

操作前必须全部打勾，任意一项未完成则当天不做 T：

- [ ] 我有底仓，本次 T 仓 ≤ 底仓的 1/3
- [ ] 我已写下今天的卖出价、接回价、止损价、放弃条件
- [ ] 预期价差 > 往返成本的 3 倍
- [ ] 今天没有重大公告、板块利空或股东减持公告
- [ ] 开盘没有跳空涨停或大幅跳空
- [ ] 我的心态稳定（不是想翻本、不是追涨杀跌、不是频繁操作）
- [ ] 我只做一轮 T

## 九、风险提示

1. **最大风险是单边行情** — 反 T 可能卖在起点，正 T 可能接在半山腰
2. **T+1 限制** — 当天买入的不能当天卖，只能用底仓
3. **趋势优先** — 如果区间被明确跌破（收盘跌破支撑位），应停止做 T
4. **成本与税务** — 多笔交易会增加汇兑、税费和税务申报复杂度，建议向专业人士咨询
5. **合规** — 确认该股票与投资限制名单无关，向券商确认清楚

## 十、常见决策

**Q: 冲高但成交量跟不上，是不是不应该卖？**  
A: 反 T 就是要在这个时候卖——等量能放出再卖会晚，容易被涨停。量能跟不上是反 T 最好的卖点。

**Q: 跌破支撑位后又反弹了，要不要补买？**  
A: 不要。跌破支撑位意味着原先的区间被破坏了，逻辑变了。用原计划处理已买的 T 仓，不追加。

**Q: 昨天 T 失败了，今天要不要继续？**  
A: 可以，但要错开最后一轮 T 的价位。不要因为昨天失败就情绪化、频繁操作或加大仓位。

**Q: 做 T 一定要卖飞或被套吗？**  
A: 不一定。规则执行到位的话，大多数是小赚或小亏。卖飞和被套是对"怕卖飞"或"怕被套"而做出的情绪化操作的惩罚。
